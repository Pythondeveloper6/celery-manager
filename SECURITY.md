# Security Policy

celery-manager is alpha software, developed in a private repository.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please report vulnerabilities privately by email to
pythondeveloper6@gmail.com. Do not open a public issue. Include the affected
version, steps to reproduce, and the impact you observed. You can expect an
acknowledgement as soon as possible; fixes ship in the next 0.1.x release.
