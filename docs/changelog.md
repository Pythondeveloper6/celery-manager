# Changelog

Every release's changes, including what breaks for development builds, are kept in
[`CHANGELOG.md`](https://github.com/Pythondeveloper6/celery-manager/blob/main/CHANGELOG.md)
in the repository, following
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Releases are published to [PyPI](https://pypi.org/project/celery-manager/#history).
